# Employee Database Management System

A modern employee management dashboard built with HTML, CSS, and JavaScript. It allows adding, editing, and deleting employee records with a user-friendly UI.

## 🔍 Features

- Add, Edit, Delete Employees
- Filter by Department
- Responsive Design
- Real-time UI Updates
- Keyboard Accessibility
